# Third-party notices

This scaffold contains no copied third-party source material.

The source register contains one public metadata entry for Backboard. Its
license is recorded as `NOASSERTION` because no license was found in the public
source metadata at registration time. The entry does not copy prompts or other
source bytes and grants no license in Backboard material.

Future third-party inclusions require a source-register entry, applicable
license notice, attribution, and explicit operator authorization.
